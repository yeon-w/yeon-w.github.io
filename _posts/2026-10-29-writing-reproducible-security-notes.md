네이버 블로그에 남겨 둔 개념·학습 기록 29편을 다시 읽었다. 처음에는 용어와 구조를 이해하는 데 집중했고, 점차 코드와 증거를 직접 확인하는 실습으로 이어졌다. 이 글은 문제별 라이트업과 별도로, 무엇을 공부했고 어디까지 확인했는지를 정리한 기록이다.

## 포너블: 메모리 구조에서 실행 흐름

포너블 기초 정리에서 메모리, 레지스터, 어셈블리와 GDB 사용법을 공부했다. 이후 스택 버퍼 오버플로우 실습에서는 입력 길이와 버퍼 크기를 비교하고, GDB로 tmp_fd 값이 덮이는 것을 확인해 정답을 제출했다.

형식 문자열 취약점은 출력 형식 지정자가 정보 읽기와 쓰기로 이어질 수 있는 원리를 정리한 글이다. 카나리 누출 실습에서는 카나리 값을 읽고 페이로드를 시험했지만 쉘 획득에는 실패했다. 결과와 실패를 함께 남겨 둔 기록이기도 하다.

그다음 ret2libc와 ROP를 공부하며 NX·ASLR 환경에서 주소를 찾고 실행 흐름을 잇는 방법을 정리했다. 취약점 스터디 최종발표에는 카나리 누출부터 ROP 체인과 GOT 변경까지의 풀이 흐름과 방어 방법을 모았다. 힙 오버플로우와 Use After Free는 청크, bin, tcache 등 힙 구조를 이해하기 위한 개념 노트다.


## ELF: 바이너리의 구조를 도구 개발로 연결

ELF 구조 분석에서는 ELF Header, 프로그램 헤더와 섹션 헤더, segment와 section의 차이, PLT·GOT 등을 정리했다. ELF 보호 기법에서는 ASLR, NX, Canary, PIE, RELRO가 각각 무엇을 보호하는지 살펴봤다.

이후 CLI 설계 글에서 분석 명령의 옵션과 출력 방식을 구상했다. 위험 함수명 탐색도 이 글에 초안으로 적었지만, 현재 개발한 ELF 분석 도구에서 완료한 기능은 구조 파싱과 보호 기법 출력이다. 설계한 기능과 구현한 기능을 구분해 기록하려 한다.

## 디지털 포렌식: 흔적을 바탕으로 사건 읽기

입문·증거, 컴퓨터 과학과 파일 시스템, 리버스 엔지니어링 기초를 정리하며 분석 대상과 기본 용어를 익혔다. 이어 Windows 포렌식 개념과 Autopsy·KAPE의 역할과 사용 방법을 공부했다.

Windows 포렌식 실습에서는 레지스트리, NTFS 로그, 이벤트 로그, Chrome History, Prefetch를 확인했다. USB 연결과 자동 실행, 파일 변경 시각, 브라우저·프로그램 실행 흔적을 서로 맞춰 보며 문제의 답을 찾았다.

Linux도 기초와 추가 학습, 포렌식 개념 정리로 익힌 뒤 실습에 적용했다. 수상한 로그인 셸과 로그 파일을 추적했고, 웹 접근 로그에서는 SQLMap 관련 요청 패턴을 역추적했다. 메모리 포렌식 글은 Volatility와 메모리 아티팩트의 분석 순서를 공부한 노트다.

## AI 보안: 에이전트 행동

LLM의 기본 개념부터 AI 에이전트 보안의 도구·메모리·외부 데이터·권한 문제로 관심을 넓혔다. AI security에서는 위협 모델과 신뢰 경계, 평가 기준을, jailbreaking에서는 역할극·다중 턴·many-shot 등 공격 방식과 성공 판정 방법을 정리했다.

개념을 익힌 뒤에는 별도의 에이전트 실험도 기록했다. 직접·간접 공격 테스트에서 테스트 입력 후 더미 파일이 생성된 사례를 남겼고, 간접 공격 재시도에서는 문서 속 지시가 최종 답변 문자열에 반영된 사례를 관찰했다. 방어 적용 기록에서는 읽기 전용 설정과 도구 권한 제한을 적용한 뒤 해당 테스트 결과를 확인했다. 이 기록들은 정해진 실습 조건에서의 관찰이며, 정보 유출이나 일반적인 방어 성공률을 뜻하지는 않는다.



분야는 달라도 공부할 때 반복해서 한 일은 비슷했다. 구조를 먼저 이해하고, 입력이나 증거가 지나가는 경로를 찾고, 예상과 실제 결과를 비교하는 것이다. 앞으로도 개념 설명, 직접 확인한 결과, 아직 해결하지 못한 부분을 분리해서 기록할 생각이다.
