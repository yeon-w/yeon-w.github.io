# 지금까지의 활동을 돌아보며

지금까지 보안 분야에서 다양한 공부와 실습을 진행하면서 새로운 기술을 배우고 직접 적용해 보는 경험을 쌓아왔다. 포너블과 ELF 파일 구조 분석, 디지털 포렌식 등을 공부하며 시스템 보안에 대한 기초를 다졌고, 최근에는 AI 에이전트의 프롬프트 인젝션과 레드티밍 실습에도 관심을 가지고 활동 범위를 넓혀왔다. 단순히 이론을 공부하는 것에서 그치지 않고 직접 실습 환경을 구축하고, 코드를 실행하며 발생하는 문제를 해결하는 과정에서 많은 것을 배울 수 있었다.

이번에 GitHub Pages를 이용해 기술 블로그를 새롭게 구축하면서 그동안의 활동을 다시 돌아볼 기회가 생겼다. 기존 네이버 블로그를 비롯해 여러 곳에 남겨둔 학습 기록을 되돌아보니, 생각보다 다양한 분야를 접하고 여러 실습을 시도해 왔다는 점에서는 의미가 있었다. 하지만 동시에 각각의 활동을 얼마나 깊이 있게 이해하고 내 것으로 만들었는지에 대해서는 아쉬움이 남았다.

**가장 크게 느낀 부족한 점은 학습의 깊이와 체계성이다.** 새로운 분야나 기술에 관심이 생기면 직접 시도해 보는 편이지만, 하나의 주제를 충분히 파고들기 전에 다른 주제로 넘어가는 경우가 있었다. 특히 실습 과정에서 오류가 발생하면 당장의 문제를 해결하는 데 집중하다 보니, 문제가 발생한 근본적인 원인이나 관련 기술의 내부 동작 원리까지 분석하지 못한 경우도 있었다. 이러한 부족함은 단순히 지식이 모자라기 때문만이 아니라, 학습을 시작할 때 명확한 목표와 완성 기준을 세우지 않았기 때문이라고 생각한다.

그동안 배운 내용을 기록하려고 노력했지만, 개념이나 해결 방법을 정리하는 데 비해 왜 그런 방법을 사용했는지, 다른 방법과 비교했을 때 어떤 차이가 있는지, 실패한 시도에서 무엇을 배웠는지를 체계적으로 남기는 부분은 부족했다. 특히 보안 분야에서는 공격이나 분석을 한 번 성공시키는 것뿐만 아니라, 결과를 재현하고 발생 원인을 설명할 수 있는 능력이 중요하다고 생각한다. 이러한 관점에서 보면 아직 실습 결과를 하나의 완성도 있는 분석으로 발전시키는 경험이 부족하다고 느꼈다.

앞으로는 이러한 부족함을 보완하기 위해 학습 방식부터 개선하려고 한다. 우선 관심 있는 분야를 무작정 넓히기보다는 일정 기간 하나의 주제에 집중하여 기초 개념부터 실제 실습, 결과 분석까지 연결하는 방식으로 공부할 계획이다. 특히 포너블과 시스템 보안에 대한 기초를 꾸준히 다지면서, 최근 관심을 가지고 있는 레드티밍과 AI 에이전트 보안 분야에서는 직접 실험을 설계하고 결과를 비교·분석하는 경험을 늘리고 싶다. 실습 과정에서도 단순히 성공 여부만 확인하는 것이 아니라, 동작 원리와 실패 원인, 실험의 한계까지 스스로 설명할 수 있는 수준을 목표로 삼으려고 한다.

또한 새롭게 구축한 GitHub 블로그를 이러한 학습 과정을 관리하고 정리하는 공간으로 활용할 생각이다. 기존의 기록을 체계적으로 정리하는 것부터 시작해 앞으로는 실습 환경, 문제 해결 과정, 시행착오, 최종 결과를 함께 기록하고자 한다. 매주 학습한 내용을 돌아보고, 한 달 단위로 주요 활동과 부족했던 부분을 점검하면서 단순히 게시글을 쌓는 것이 아니라 이전보다 얼마나 성장했는지를 확인할 수 있도록 할 계획이다.

이번 회고를 통해 그동안 새로운 기술을 접하고 직접 시도하는 데에는 적극적이었지만, 그 경험을 깊이 있는 이해와 완성도 있는 결과물로 연결하는 과정은 상대적으로 부족했다는 것을 깨달았다. 앞으로는 많은 것을 경험하는 것 자체에 만족하기보다, **하나의 문제를 스스로 분석하고 해결한 뒤 그 과정과 결과를 다른 사람에게 설명할 수 있는 역량**을 갖추고 싶다. 지금까지 쌓아온 경험을 바탕으로 부족한 부분을 꾸준히 채워 나가면서, 단순히 보안 기술을 공부하는 사람에서 실제 보안 문제를 발견하고 분석할 수 있는 사람으로 성장하는 것이 앞으로의 목표이다.

분야는 달라도 공부할 때 반복해서 한 일은 비슷했다. 구조를 먼저 이해하고, 입력이나 증거가 지나가는 경로를 찾고, 예상과 실제 결과를 비교하는 것이다. 앞으로도 개념 설명, 직접 확인한 결과, 아직 해결하지 못한 부분을 분리해서 기록할 생각이다.
